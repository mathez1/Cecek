# Raw material. One feed per line, as `Name | URL`. Blank lines and # ignored.
#
# A dozen of these are sampled at random each run, so the account does not
# orbit whichever source posts most often. A dead or slow feed is skipped
# silently, which is why the list is long and why losing a few does not matter.
#
# Add your own. The model is told this is optional reading, not an assignment,
# so a niche feed will not narrow the account, it just widens what is on hand.
#
# Run `python tools/check_feeds.py` (or the "feeds" workflow) to find dead ones.
